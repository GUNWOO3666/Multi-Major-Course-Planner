# 웹 실행 안내

MySQL에 저장된 두 학과의 강좌·강의시간을 조회하여 시간표를 구성하고 충돌을 확인하는 웹입니다. 프로젝트 소개, 첫 실행, 충돌 탐지 시연, MySQL 구성은 **[저장소 첫 화면의 README](../README.md)**에 정리되어 있습니다.

## 빠른 체험 실행

1. **Node.js 20 이상**을 설치합니다.
2. Windows에서는 이 폴더의 **`start.cmd`를 더블클릭**합니다.
3. 브라우저에서 http://127.0.0.1:3000 이 열립니다.

별도 패키지 설치나 `npm install`은 필요하지 않습니다. DB 환경 구성 전에도 간편하게 시연할 수 있도록 **MySQL 입력 자료와 동일한 67개 분반의 데이터 복사본**을 함께 제공합니다. 처음에는 이 자료로 실행되고, MySQL을 연결하면 실제 DB 조회 결과를 사용합니다. 복사본은 `public/data.json`이며 별도의 DB 서버는 아닙니다.

실행 창을 열어 두고 사용하세요. 창에서 Enter를 누르면 서버가 종료됩니다.

터미널에서 실행하려면 이 폴더에서 다음 명령을 사용합니다. Windows/macOS/Linux에서 Node.js 20 이상이 필요합니다.

```sh
node server.mjs
```

터미널에서 Ctrl+C로 종료합니다.

## 기능 확인

**예시 담기** → 프로그래밍입문(2) 11001과 신호및시스템 21001의 **화요일 1~2교시 충돌**을 확인합니다. 프로그래밍입문(2)을 11003 분반으로 교체하면 위 두 강좌 사이의 충돌이 해소됩니다.

선택한 강좌는 같은 브라우저에 자동 저장됩니다. 내려받기 버튼으로 선택 내역을 JSON 파일로 저장할 수 있습니다.

## MySQL 연동 실행

[루트 README의 MySQL 연결 안내](../README.md#4-mysql-연동-실행)에 따라 본인 PC에 DB를 구성한 뒤, 웹 오른쪽 위 **제공 자료 · DB 연결 전**을 누릅니다. 사용자 이름·비밀번호·포트를 입력하고 **MySQL 연결됨**을 확인합니다.

- 기본 DB 이름: `multi_major_planner`
- 접속 주소: `127.0.0.1`
- 기본 MySQL 포트: `3306`
- 기본 실행 파일: `C:\Program Files\MySQL\MySQL Server 8.0\bin\mysql.exe`
- 웹은 읽기 전용으로 조회하며, 비밀번호는 서버 메모리에만 보관합니다.

코업 등 시간 의미를 확인해야 하는 분반은 **시간 확인 필요**로 표시합니다. 전필/전선은 개설 화면 기준이고, 학생별 졸업요건 판정은 포함하지 않습니다.

## 자동 검증

이 폴더에서 실행합니다.

node --test
