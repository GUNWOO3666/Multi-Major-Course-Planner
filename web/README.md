# Multi-Major Course Planner 웹

서울과학기술대학교 2026년 2학기 두 학과 강좌를 선택하는 PC용 웹입니다.

## 실행

1. 이 폴더의 **start.cmd**를 더블클릭합니다.
2. 브라우저에서 **http://127.0.0.1:3000**이 열립니다.
3. 실행 창은 사용하는 동안 열어 두세요. Enter를 누르면 서버가 종료됩니다.

Node.js 20 이상이 필요합니다. 현재 PC의 Codex에 포함된 Node도 자동 탐색합니다.
따로 설치할 패키지는 없습니다. Node가 PATH에 있다면 터미널에서 `node server.mjs`로도 실행할 수 있습니다.

## 사용

- 왼쪽에서 과목·교수·과목코드·강좌번호 검색, 학과와 이수구분 필터를 사용합니다.
- `담기 +`로 분반을 선택합니다. 같은 과목의 다른 분반은 기존 분반을 교체합니다.
- 같은 요일의 교시 범위가 겹치면 빨간색 표시와 충돌 내역이 나옵니다. 종료 교시를 포함합니다.
- `예시 담기`는 프로그래밍입문(2) 11001과 신호및시스템 21001을 담습니다. 화요일 1–2교시 충돌입니다.
- 선택은 이 브라우저에 자동 저장됩니다. 비공개 모드나 저장소 제한에서는 유지되지 않을 수 있습니다.
- 내려받기 버튼으로 선택과 충돌 내용을 JSON 파일로 저장합니다.
- 주말 표시를 켜면 토·일 강의를 볼 수 있습니다. 교시는 실제 시각으로 추정 환산하지 않습니다.

## 기존 MySQL 연결

처음에는 입력 SQL과 같은 화면 자료의 **67개 분반 스냅샷**을 보여줍니다. DB 실시간 연결은 아닙니다.
오른쪽 위 `제공 자료 · DB 연결 전`을 누르고, Workbench에서 사용하는 사용자·비밀번호·포트를 입력하세요.
연결에 성공하면 `MySQL 연결됨`으로 바뀌며 실제 DB에서 Course, Section, Department, ClassSchedule을 JOIN해 조회합니다.
`multi_major_planner` DB에 앞서 실제 자료 입력/복구 SQL이 완료되어 있어야 합니다.

- 서버는 이 PC의 127.0.0.1에만 열립니다. 인터넷 배포를 하지 않습니다.
- MySQL 접속 비밀번호는 서버 메모리에만 보관하며 파일이나 localStorage에 저장하지 않습니다.
- 읽기 전용 SELECT만 실행하며 데이터나 테이블을 변경하지 않습니다. SELECT 권한만 있는 별도 사용자도 사용할 수 있습니다.
- 연결 해제나 서버 종료 시 접속 정보는 사라집니다. 브라우저에서 연결 해제하면 제공 자료 모드로 돌아옵니다.
- 기본 MySQL 실행 파일 위치: `C:\Program Files\MySQL\MySQL Server 8.0\bin\mysql.exe`.
  다른 위치라면 실행 전에 PowerShell에서 `$env:MYSQL_BIN='실제 mysql.exe 절대경로'`를 설정하세요.
- 3000 포트가 사용 중이면 `$env:PORT='3001'`을 설정하고 실행할 수 있습니다.

## 자료의 범위

- 사용자 제공 2026-2 화면 기준: 컴퓨터공학과 40개, 스마트ICT융합공학과 27개 분반. 46개 과목, 79개 일반 강의시간.
- 1학기 자료는 이번 웹에 포함하지 않았습니다.
- 전필/전선은 `Section.offered_course_type` 기준입니다. CurriculumCourse 적용 연도·추천 학년은 확인되지 않아 졸업요건을 판정하지 않습니다.
- 코업/코업프로젝트 4개는 `NEEDS_REVIEW`로 경고하며 정상 시간표 블록으로 배치하지 않습니다. 이들을 충돌이 없다고 판단해서는 안 됩니다.
- 강의실 배정이 불명확한 경우 원문을 보존하고 `강의실 확인 필요`로 표시합니다.
- 학교 수강신청을 대신하지 않습니다. DB에 수강 계획을 저장하는 Student/PlannedSection 기능은 아직 포함하지 않았습니다.

## 확인

`node --test`: 실제 충돌 예시, 경계 교시·다른 학기 판정, 중복 학점, 저장값 복구, 겹친 블록 배치, 자료 개수를 검사합니다.

주요 파일: `server.mjs` (로컬 서버/MySQL 조회), `public/app.js` (화면 동작), `public/planner.mjs` (충돌 판정), `public/data.json` (제공 자료).
